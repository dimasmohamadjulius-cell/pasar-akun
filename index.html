Data Akun di GitHub

Situs ini membaca data dari file accounts.json di repo GitHub. Perubahan di tab Kelola tersimpan lokal di perangkat ini sebagai cadangan — terbitkan ke GitHub agar terlihat oleh semua pengunjung.

Memuat data…
  1. Klik “Salin data akun (JSON)” di bawah untuk menyalin data terbaru (pengaturan, tema, dan semua akun).
  2. Buka repo dimasmohamadjulius-cell/pasar-akun-data, buka file accounts.json, lalu klik ikon pensil (Edit).
  3. Hapus isi lama, tempel JSON yang disalin, lalu klik Commit changes. Situs terbarui otomatis dalam beberapa menit.
